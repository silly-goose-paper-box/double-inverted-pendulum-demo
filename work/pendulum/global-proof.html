可达性边界与证明

有限轨道与有限推力下，存在任何控制器都无法挽救的初态

在默认模型中，取小车初始位置 0 m、速度 14 m/s 向右，两杆均为 −180° 且角速度为零。即使控制器可以任意选取满足限幅的推力，小车也会在 0.4993 s 内越过轨道边界。以下证明适用于所有控制方式，包括时变和非线性控制器。

1. 质心水平动量

令总质量 mΣ = M + m1 + m2。以 Y 表示总质量乘以水平质心位置，P 表示系统的水平动量。α、β 与上方动力学方程中的定义相同。

Y = mΣx + α sin θ₁ + β sin θ₂ P = dY/dt = mΣẋ + α cos θ₁·θ̇₁ + β cos θ₂·θ̇₂ dP/dt = u − bẋ

第三式由非线性动力学的第一行直接得到。重力为竖直力，两杆的关节作用力是内部力，在总水平动量方程中相消。忽略轨道端点碰撞时，受限输入下的运动可积分到任意有限时刻。机械能变化率为 uẋ − bẋ²，默认 b > 0 时它不超过 U²/(4b)。重力势能有下界，且惯性矩阵在角度空间上一致正定，因此速度不会在有限时间内发散。

2. 保持在轨道内的必要条件

记轨道端点为 ±X，推力限幅为 ±U。取零外加扰动，假设在 [0, t] 内小车始终满足 |x| ≤ X。由 u ≥ −U 及 x(s) − x0 ≤ X − x0，对任意 s ∈ [0, t] 有

P(s) = P₀ + ∫₀ˢ u(τ)dτ − b[x(s) − x₀] ≥ P₀ − Us − b(X − x₀) Y(t) − Y₀ ≥ a·t − Ut²/2，a = P₀ − b(X − x₀) Y(t) − Y₀ ≤ mΣX + α + β − Y₀

第三式使用了 x ≤ X 和 |sin θi| ≤ 1。当 a > 0，取 t = a/U，位移下界达到最大值 a²/(2U)。左侧边界可对位置与动量同时取反得到。令 σ = +1 表示右侧，−1 表示左侧，记 [a]+ = max(a, 0)。保持在轨道内必须同时满足

[σP₀ − b(X − σx₀)]+² / (2U) ≤ mΣX + α + β − σY₀，σ ∈ {−1, +1}

任一侧不等式被严格违反，即可判定该初态会越轨。两侧都满足时，还需另外检验从该状态能否摆起和捕获。

3. 代入默认参数的反例

mΣ = 1.30 kg，α = 0.10 kg·m，β = 0.02 kg·m X = 2.8 m，U = 36 N，b = 0.08 N·s/m Y₀ = 0，P₀ = 1.30 × 14 = 18.20 kg·m/s a = 18.20 − 0.08 × 2.8 = 17.976 kg·m/s，t = 17.976/36 ≈ 0.4993 s Y(t) ≥ 17.976²/72 = 4.488008 kg·m |x(t)| ≤ 2.8 m ⇒ Y(t) ≤ 1.30 × 2.8 + 0.10 + 0.02 = 3.76 kg·m

上下界矛盾，所以在给定时刻之前必然已越轨。对任意正的有限轨道长度和有限推力上限，继续增大初始小车速度同样会得到矛盾。因此只修改有限轨长、质量或增益，也无法保证任意初态都能回到直立点。

4. 两杆下垂时的开环反例

令两杆均为 −180°，小车和两杆都静止，使用零开环推力。此时重力项含有的 sin θ₁、sin θ₂ 都为零，所有速度项也为零。惯性矩阵可逆，因此三个加速度均为零。由该光滑动力学的解唯一性，系统将一直停在下垂平衡点。直立点附近设计的线性反馈则需要先进入其捕获范围，有限轨道与推力下的全局保证仍受上述反例约束。

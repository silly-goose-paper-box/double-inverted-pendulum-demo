# 小车双倒立摆仿真台

在浏览器中观察小车如何用水平推力把两根串联摆杆从下垂摆到直立，并比较不同的稳摆控制器。页面包含实时动画、状态曲线、参考位置跟踪、外力扰动、CSV 导出和直立点状态空间模型。

## 1. 下载与运行

1. 下载 [double-inverted-pendulum.html](double-inverted-pendulum.html)。也可以用仓库的 **Code → Download ZIP** 下载后解压。
2. 双击下载到本机的 HTML，用支持现代 JavaScript 和 Canvas 的浏览器打开，例如 Chrome、Edge 或 Firefox。
3. 点击页面顶部的 **运行仿真**。默认小车在轨道中心，两杆都从 −180° 下垂静止释放，目标是回到中心并保持双杆直立。
4. 仿真进入 **轨迹摆起** 后，先观察小车为摆杆注入能量的过程。状态变为 **直立反馈** 时，所选的稳摆控制器已接管。

GitHub 的文件浏览页用于查看或下载 HTML。请在本机浏览器中打开下载后的文件来运行仿真。运行成品无需安装 Node.js、MATLAB、Python 或启动 Web 服务。HTML 已内嵌脚本和样式，可离线使用。

## 2. 常用操作

| 操作 | 使用方法 | 需要留意 |
| --- | --- | --- |
| 启停 | 点击 **运行仿真**、**暂停仿真** 或 **继续仿真** | 在计算轨迹时，同一按钮可取消规划 |
| 单步 | 暂停后点击 **单步 10 ms** | 首次单步可能先计算摆起轨迹 |
| 重置 | 点击顶部 **重置** | 回到已设置的初始状态，清空历史和控制器内部状态。控制器与参考位置设置继续生效 |
| 播放速度 | 选择 0.25×、0.5×、1×、2× 或 4× | 只改变动画推进速度。控制周期仍为 10 ms，积分步长仍为 5 ms |
| 修改控制器 | 在 **控制方式** 选择一项，修改字段，再点击 **应用控制器** | 看到“待应用”时，仿真仍使用上一份已应用配置 |
| 恢复默认 | 点击 **恢复默认值**，再点击 **应用控制器** | 恢复当前选中模式的字段。需要同一起点比较时，再点击 **双杆下垂** |

| 自定义初态 | 展开 **初始状态**，填写六个量，点击 **应用并重置** | 角度用度，角速度用度每秒。小车初始位置须严格在轨道内部 |
| 扰动 | 稳摆后点击 **推左** 或 **推右** | 每次给小车叠加 ±8 N，持续 0.12 s。曲线和 CSV 可用于比较恢复过程 |
| 看曲线 | 调整曲线窗口到 6、12、24 或 60 秒 | 窗口只影响显示。CSV 导出本次重置以来的全部采样记录 |
| 切换动力学 | 在 **仿真动力学** 中选非线性方程或直立点线性化 | 切换会重置仿真。线性化适合直立附近小偏角，自动摆起使用非线性模型 |

### 推荐实验

1. **复现从 −180° 摆起。** 先点 **归零**。选择所需控制器，依次点 **恢复默认值**、**应用控制器**，确认开启 **自动摆起并接管**，再点 **双杆下垂** 和 **运行仿真**。检查两杆角度趋于 0°、小车回到 0 m。
2. **比较位置跟踪。** 双杆稳住后点 **+0.25 m**，记录小车的过冲、稳定时间、两杆最大倾角和峰值推力。改变控制器后用相同初态重复。积分控制还可用于对比持续偏置下的位置误差。
3. **比较扰动恢复。** 待小车和两杆再次静止后施加同方向推力，记录最大位置偏移、角度偏差及恢复时间。若想比较控制律本身，使用相同参考位置、初态和扰动时刻。
4. **观察纯开环。** 选择 **开环 · 信号发生器** 并应用，关闭 **自动摆起并接管**，从 **双杆下垂** 启动。直流和正弦幅值均为零时，理想模型会留在下垂平衡点。可用 **直立小偏角** 初态观察直立平衡附近在零推力下的发散。
5. **理解约束反例。** 点击页面底部 **载入反例并判定**。页面将两杆置于下垂，并将小车初速度设为向右 14 m/s，演示有限轨道和有限推力为何限制可恢复初态。

## 3. 控制器怎么选

默认运行使用完整的非线性模型。各反馈模式开启自动摆起时，先跟踪同一类有限轨道、有限推力下的摆起轨迹，再使用所选控制器稳摆。可关闭自动摆起，从 **直立小偏角** 开始单独比较稳摆控制律。专用摆起模式固定使用非线性模型。

| 模式 | 实现和主要字段 |
| --- | --- |
| 非线性摆起 → LQR 稳定 | 轨迹规划与跟踪后，由默认 LQR 稳摆。适合直接体验完整过程 |
| LQR · 最优反馈 | 对 10 ms 零阶保持离散模型求 LQR，输入六项对角权重 $Q$ 和推力权重 $R$ |
| 极点配置 | 用 Ackermann 公式配置六个负实数连续闭环极点。实际以 10 ms 周期计算并保持推力 |
| LQI · 带积分的 LQR | 把小车位置误差积分作为第七个状态。可调 $Q$、积分权重 $Q_i$、$R$ 和积分限幅 |
| PID + 双摆角 PD | 小车位置 PID 与两路摆角 PD 并联。输入位置 $K_p,K_i,K_d$ 及两杆的比例、微分增益，使用页面给定的符号 |
| MPC · 约束预测控制 | 用线性模型与 Riccati 末端代价求解输入约束问题，执行首步推力。默认预测 28 步（0.28 s），稳摆推力约束 ±30 N，摆起阶段使用系统限幅 |
| 观测器 + LQR | 稳摆阶段使用位置和两杆角度测量，通过降阶观测器估计速度。默认误差衰减率为 55 s⁻¹。共用摆起轨迹跟踪使用全状态 |
| SMC · 滑模控制 | 用五个负实数极点设计滑模面，以线性趋近项和平滑的边界层切换项计算推力。可调趋近速率、切换幅值和边界层宽度 |
| 手填状态反馈 K | 按 $[x,\theta_1,\theta_2,v,\omega_1,\omega_2]$ 的顺序输入六个增益，采用 $u=-K(z-z_r)$ |
| 开环 · 信号发生器 | 生成直流加正弦推力。自动摆起开启时，直立阶段将信号叠加在 LQR 稳摆力上。关闭自动摆起后，推力仅由信号发生器给出 |
| 自定义公式 | 输入控制力表达式和最多三个内部状态的导数。默认表达式为直立状态反馈示例 |

LQR、LQI、MPC 和观测器稳摆的共享默认权重为 $Q=\mathrm{diag}(20,150,150,8,2,2)$，$R=0.8$。位置积分控制采用积分限幅，在输出饱和时抑制积分继续累积。大增益或很快的目标极点会提高推力需求，应用后仍需用曲线确认实际响应。

### 自定义控制律

可使用 `x`、`th1`、`th2`、`v`、`w1`、`w2`、`r`、`ex`、`t`、`dt` 及内部状态 `s1`、`s2`、`s3`。`ex = x - r`，角度变量按弧度折回至 ±π。运算支持四则、幂、比较及 `sin`、`cos`、`tanh`、`clamp`、`if` 等函数。

默认公式可作为修改起点：

```text
119.3952*th1 - 152.9691*th2 - 3.1623*ex - 5.8254*v + 0.4434*w1 - 19.6260*w2
```

要试验位置积分，可在 **动态控制器状态** 填 `ds1/dt = ex`，然后在推力公式中加入 `- 数值增益*s1`。状态从零开始，按 $s\leftarrow s+dt\cdot\dot s$ 更新。积分增益需要重新验证。公式解析出错或在运行中产生无穷大时，页面会提示。运行时异常后可先重置，再调整公式和应用。

## 4. 模型、单位与数据

状态向量为 $z=[x,\theta_1,\theta_2,\dot{x},\dot{\theta}_1,\dot{\theta}_2]^T$。小车向右为正，两杆都从竖直向上独立量角，向右倾为正。第二杆角度是相对竖直的绝对角。输入 $u$ 是小车水平推力。位置指令 $r$ 对应直立平衡状态 $z_r=[r,0,0,0,0,0]^T$。无稳摆控制的直立平衡点对小扰动不稳定。

| 参数 | 默认值 |
| --- | ---: |
| 小车质量 | 1.00 kg |
| 下杆 / 上杆质量 | 0.20 / 0.10 kg |
| 下杆 / 上杆长度 | 0.50 / 0.40 m |
| 重力加速度 | 9.81 m/s² |
| 小车黏性阻尼 | 0.08 N·s/m |
| 转轴黏性阻尼 | 0 N·m·s/rad |
| 小车允许位置 | ±2.8 m（总行程 5.6 m） |
| 执行器限幅 | ±36 N |
| 控制周期 / RK4 积分步长 | 10 ms / 5 ms |

页面提供随构型变化的惯性矩阵和非线性方程，以及直立点连续线性化 $\dot z=Az+Bu$。每个控制周期内，执行器推力做零阶保持，模型用两次 5 ms 四阶 Runge–Kutta 更新。外力扰动在执行器限幅之后叠加，因此模型承受的总水平外力可以超过执行器单独的限幅。越轨时仿真停止，页面未模拟端点碰撞。

点击 **导出 CSV** 获取以下列：

| 列名 | 含义 |
| --- | --- |
| `t_s` | 仿真时间，s |
| `x_m`、`reference_m` | 小车位置与位置指令，m |
| `theta1_rad`、`theta2_rad` | 两杆连续角度，rad |
| `v_m_per_s` | 小车速度，m/s |
| `omega1_rad_per_s`、`omega2_rad_per_s` | 两杆角速度，rad/s |
| `control_N`、`disturbance_N` | 限幅后的控制推力与外加扰动记录，N |

动画和角度曲线会将角度折回到 ±180°。CSV 保留连续转角，分析跨过 ±π 的数据时可按需要折回，例如用 `atan2(sin(theta), cos(theta))` 计算相对直立点的误差。

### MATLAB / Simulink 对照

在 **状态空间与动力学** 点击 **复制 MATLAB 矩阵**，把生成的 `A`、`B`、`C`、`D` 粘贴到 MATLAB。使用 Control System Toolbox 时，可用下面的代码复现默认 LQR 的设计模型。

```matlab
% 先粘贴页面提供的 A、B、C、D
Ts = 0.01;
sysd = c2d(ss(A,B,C,D), Ts, 'zoh');
Q = diag([20 150 150 8 2 2]);
R = 0.8;
[K, P, poles] = dlqr(sysd.A, sysd.B, Q, R);
```

在 Simulink 的 State-Space 模块中使用同一组连续矩阵，可以做直立附近小扰动对照。若要复现 −180° 摆起，需要实现页面给出的非线性动力学、摆起轨迹、限幅、控制切换和对应采样。导出的 CSV 可作为对比参考。

## 5. 摆起是怎样实现的

规划器从随仓库提供的轨迹种子中选择与初态接近的候选，并利用角度等价与镜像扩展候选。必要时进行分段轨迹修正，或用有界迭代 LQR 搜索。找到候选后，按相同的 5 ms 非线性模型重放轨迹检查轨道与推力，并试跑所选稳摆控制器接管后的 5 s。运行时使用时变反馈跟踪轨迹，完成后切换到稳摆控制器。

若界面提示“轨道约束不可满足”，页面的质心水平动量必要条件已给出反例。向右 14 m/s 的默认反例中，约 0.4993 s 时质心位移下界为 4.488 kg·m，超过轨道允许的 3.760 kg·m 上界。若界面提示“未找到可行轨迹”，表示有限搜索预算内没有找到通过验证的候选，这时仍无法判定该初态是否可达。

## 6. 已验证工况与测试命令

在小车居中、参考为 0 m、两杆均为 −180°、全部速度为零的默认无扰动工况下，使用已构建 HTML 逐档回放了 **11 种默认配置**。名义摆起耗时约 **2.64 s**，小车峰值绝对位移 **1.038 m**，执行器峰值推力 **16.65 N**。每档运行到 20 s，最后 10 s 内双杆角误差均小于 $10^{-4}$ rad（约 0.006°）。

另在专用摆起模式验证了 **72 项回放**，包含小车居中、全部速度为零时两杆每隔 45° 取样的 64 组组合，以及 8 项代表工况。对照脚本还覆盖了直立反馈、位置阶跃、短时扰动、纯开环响应、矩阵复制、单步和 CSV 导出。这些是给定模型与有限工况下的数值结果，初态、控制律、参数或扰动改变后应重新验证。

## 8. 常见问题

- **下载后只看到源码。** 确认文件后缀为 `.html`，并用浏览器打开本地文件。GitHub 的代码浏览页不会启动仿真。
- **更换控制器后行为没变。** 查看面板是否提示“待应用”。点击 **应用控制器**，再从相同初态重新运行。
- **两杆从下垂不动。** 确认使用非线性动力学并开启 **自动摆起并接管**。纯开环默认推力为零，理想模型会留在下垂平衡点。
- **规划失败或越轨。** 先试 **归零**、**恢复默认值**、**应用控制器** 和 **双杆下垂**，复现默认工况后逐项改变设置。若载入的是 14 m/s 反例，恢复默认初态才能重新摆起。
- **图上角度突然从 +180° 到 −180°。** 这是同一物理方向在折回坐标下的跳转。连续角度可从 CSV 查看。
- **矩阵复制不可用。** 如浏览器阻止本地页面访问剪贴板，可从页面提供的 MATLAB 矩阵文本框手动复制。
